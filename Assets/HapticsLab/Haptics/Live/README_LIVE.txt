HAPTICS LAB - LIVE FOLDER

Export .haptic files from Haptics Studio into this folder while the lab is playing.
The Design Bench picks up new or changed files within a second and selects them.

Put the audio file with the same name next to it (e.g. MyClip.haptic + MyClip.wav)
to hear the sound together with the haptics.

Files here are also imported by Unity as normal HapticClip assets, so you can use
them in your own scenes afterwards.
